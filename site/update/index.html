AvatarRecovery
Update Guide

AvatarRecovery Update Notifier does not install updates. Open your project in VCC or ALCOM, then update AvatarRecovery to the latest published version.

  1. Close the target project in Unity.
  2. Open the project in VCC or ALCOM.
  3. Open the project's package list and update AvatarRecovery to the newest available version.
  4. Reopen the project in Unity.

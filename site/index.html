Update Notifier

Get a notification in the Unity Editor when a new version of AvatarRecovery is available.

Add to VCC / ALCOM View on GitHub

Safe, notification-only updates

Checks only when needed

If AvatarRecovery is not installed in the project, automatic checks make no network request.

No automatic installation

The notifier never modifies Packages or Assets. Updates remain a manual action in your package manager.

Unity 2022.3 support

The notifier can report newly published versions even when the project contains an older AvatarRecovery release.
